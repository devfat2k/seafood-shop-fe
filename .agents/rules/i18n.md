# Internationalization (i18n) Rules

## Key Conventions & next-intl
- **No Hardcoded Strings**: Never hardcode user-visible Vietnamese or English text directly inside JSX components.
- **Translation Files**: Maintain translation dictionaries under `src/locales/` (e.g. `vi.json`, `en.json`).
- **Hook & Function Usage**:
  - Server Components: Use `getTranslations('Namespace')`.
  - Client Components: Use `useTranslations('Namespace')`.
- **Page Namespaces**: Page-specific namespaces end with `Page` (e.g., `HomePage`, `ProductsPage`).
- **Rich Text & Formatting**: Use `t.rich(...)` for inline markup within translation strings. Follow sentence case for all key values.
