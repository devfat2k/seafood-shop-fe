# Pre-Implementation Checklist

Before starting implementation of any feature or bug fix:

- [ ] Read the relevant specification in `.agents/specs/` or `docs/specs/`.
- [ ] Review architecture rules in `GEMINI.md` and domain rules in `.agents/rules/`.
- [ ] Confirm API contracts and data models in `docs/specs/api-contract.md`.
- [ ] Verify if reusable UI components exist in `src/components/ui/`.
- [ ] Clarify any ambiguous requirements or design specifications with the user.
